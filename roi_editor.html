Editor de Área de Interesse

Carregue uma imagem, clique para marcar os vértices de uma região e gere coordenadas em JSON para usar no seu código Rust/OpenCV.

1. Imagem e desenho da região

Coordenadas: 640 × 480
Clique na imagem para adicionar vértices no sentido horário ou anti-horário. Clique em “Fechar polígono” para ligar o último ponto ao primeiro. Você pode continuar movendo pontos clicando em “Desfazer ponto” e marcando novamente.
Carregue uma imagem ou use a imagem de exemplo para começar.

2. Parâmetros e JSON

A imagem é desenhada dentro de uma área fixa de 640 × 480. Se a imagem carregada tiver outra resolução, ela será redimensionada para essa referência; as coordenadas geradas correspondem a essa imagem de referência.

JSON gerado

No OpenCV, pontos podem ser convertidos para opencv::core::Point e o polígono pode ser usado como máscara ou região de interesse. O JSON não é consumido diretamente por Rect, que representa apenas retângulos.
